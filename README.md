# Shuttle Stop Crowd Ranking

## The problem I chose was the Shuttle Stop Crowd Ranking. It ranks shuttle stops based on crowd size to help determine where additonal shuttles should be sent.

## The algorithm I chose was merge sort. I chose to use merge sort as it is reliable and efficient with a constant time complexity of O(n log n). It can handle lists of any size with consistent results. Data does not have to be pre-sorted for merge sort. Merge sort visualizes the step by step process well. The user will see the left and right half of the merge for each step, along with the merged result.

## Problem Breakdown & Computational Thinking

**Decomposition**

- Read user input

- Split user input into lines

- Extract the stop and crowd count for each line

- Ensure each line has a comma, and that crowd count is a non-negative integer

- Apply merge sort by recursively splitting the list into halves then comparing and merging sorted halves

- Store each merge step and display in the GUI

- Output the final sorted ranking of shuttle stops by crowd count

**Pattern Recognition**

- Shuttle stops are compared based on the crowd count at each

- We sort it with merge sort by splitting the list into smaller halves

- Process each sublist by comparing values, selecting the larger value and appending it to the result

**Abstraction**

- Important
  
  - Stop name
  
  - crowd count
  
  - left and right sublists during each merge step
  
  - merged result for each step
  
  - final sorted output

- Unimportant
  
  - recursive call stack
  
  - tracking variables
  
  - memory operations during merging

**Algorithm Design**

- Input
  
  - Lines containing stop_name and crowd_count
  
  - One entry of each per line, seperated by a comma

- Process:
  
  - Parse and validate input
  
  - convert input into a list of tuples
  
  - apply merge sort to the list
  
  - store each merge step for visualization

- Output
  
  - Step by step sorting process
  
  - final sorted ranking of shuttle stops by crowd count

- Constraints
  
  - crowd_count must be a non-negative integer
